# Pat Salon — interactive HTML mockup

## เปิดเดโม

- `customer.html` — หน้าลูกค้าสำหรับเข้าจาก LINE แบบแอปมือถือ มีเมนูหน้าหลัก จองคิว สมาชิก และประวัติ
- `index.html` — หน้าร้าน: dashboard ปฏิทิน โปรโมชั่น และลิงก์เปิดหน้าลูกค้า

เปิดไฟล์ด้วยเบราว์เซอร์ได้ทันที รูปและฟอนต์ต้องใช้อินเทอร์เน็ต หากต้องการให้สองหน้ารับข้อมูลการจองร่วมกันอย่างแน่นอน ให้เปิดผ่าน local server จากโฟลเดอร์นี้:

```sh
python3 -m http.server 8000
```

เข้าที่ `http://localhost:8000/customer.html` และ `http://localhost:8000/index.html` ด้วยเบราว์เซอร์เดียวกัน ปฏิทินร้านอ่านการจองจากหน้าลูกค้าเมื่อเปิดหน้า กลับมาโฟกัส หรือได้รับการเปลี่ยนแปลง localStorage

## ขั้นตอนสาธิต

1. หน้าลูกค้าใช้สมาชิกทดลอง คุณลลิตา มี 480 แต้ม
2. จองตัดผม / ช่างมิน / 10 ก.ย. 2569 / 09:00 จะพบคิวซ้อน ต้องยอมรับรอ 60 นาที
3. ยืนยันแล้วดูนัดหมายในเมนูประวัติ ข้อมูลยังอยู่หลังรีเฟรช แต้มไม่เพิ่มจากการจอง
4. หน้าสมาชิก กดแลกส่วนลด ฿100 และยืนยันใช้ 200 แต้ม แต้มจะเหลือ 280 พร้อมคูปอง 1 ใบ
5. จองครั้งถัดไป แล้วเลือกคูปองสมาชิกในช่องสิทธิพิเศษ คูปองถูกใช้เมื่อยืนยันจองสำเร็จ
6. ประวัติใช้บริการมีรายการตัวอย่างและปุ่มจองอีกครั้ง
7. เปิดปฏิทินร้านแล้วเลือกวันที่ที่จอง เช่น 10 ก.ย. 2569 จะเห็นรายการลูกค้าพร้อมสถานะยอมรับรอ

## ภาพลักษณ์และขอบเขต

- ชื่อร้านและลิงก์อ้างอิงจาก https://www.facebook.com/patsalon.hairstyle ตามผู้ใช้ระบุ
- เครื่องมืออ่านภาพเพจ Facebook ไม่สำเร็จ โทนครีม–น้ำตาลและตัวอักษร PAT จึงเป็นแนวออกแบบชั่วคราว ยังไม่ได้ยืนยันสีหรือโลโก้จริง
- ภาพจาก Unsplash เป็นภาพประกอบ ไม่ใช่ผลงานหรือภาพร้านจริง
- ราคา ชื่อช่าง เวลาเปิด 09:00–19:00 โปรโมชั่น และกติกาแต้มทั้งหมดเป็นข้อมูลเสนอสำหรับเดโม
- หน้าลูกค้าอ้างอิง 10 ก.ย. 2569 ส่วนข้อมูล dashboard เดิมอ้างอิง 8 ก.ย. 2569
- แต้มตัวอย่าง: ทุกยอดสุทธิ ฿25 ได้ 1 แต้มหลังใช้บริการแล้ว; 200 แต้มแลกคูปอง ฿100; ไม่มีการเพิ่มแต้มจากการจอง
- SPA150 ใช้กับสปาผมเดือนกันยายน 2569 เท่านั้น ไม่ใช้ร่วมคูปองสมาชิก
- หน้าลูกค้าเก็บข้อมูลใน localStorage ของเบราว์เซอร์นี้ ไม่ใช่ฐานข้อมูลกลางหรือข้อมูลข้ามอุปกรณ์ การเปิดแบบ file:// อาจแยก storage ตามเบราว์เซอร์
- การจองในหน้าร้านเดิมยังอยู่ในหน่วยความจำ ไม่ส่งกลับหน้าลูกค้า รายได้และกราฟยังเป็นข้อมูลตัวอย่าง
- ไม่มี LINE Login / LIFF / การส่งข้อความ / รับชำระเงินจริง สมาชิกถูกจำลองว่าเข้าสู่ระบบแล้ว
- ยังไม่มีระบบยกเลิก เปลี่ยนวัน หรือเจ้าหน้าที่ปิดงานเพื่อเพิ่มแต้ม
- รีเซ็ตข้อมูลลูกค้า: ลบ localStorage key `pat-salon-customer-v1` ผ่านเครื่องมือเบราว์เซอร์

## การตรวจสอบ

ทดสอบบน Chrome ด้วย Playwright: จอ 320, 390, 480 และ 1280px ไม่มี horizontal overflow, บังคับยอมรับรอ, จองสำเร็จ, เก็บข้อมูลหลังรีเฟรช, แต้มไม่เพิ่มเมื่อจอง, ยืนยันแลกแต้ม, ใช้คูปองครั้งเดียว, ประวัติและจองซ้ำ, ป้องกันบริการเกินเวลาปิดร้าน, ลิงก์หน้าลูกค้า และไม่มี JavaScript runtime error ระหว่างการทดสอบ
